# Security policy

## Reporting a vulnerability

Please **don't open a public issue** for security problems.

Use GitHub's private reporting instead: go to the **Security** tab of this repo and choose **Report a vulnerability**.

Include what the problem is, how to reproduce it, and which script and version it affects. I'll aim to reply within a few days.

## Using these scripts safely

- These scripts run as **SYSTEM** on managed devices. Read them before you deploy them.
- Test in a pilot group first.
- Never commit tenant IDs, secrets, tokens, internal server names or device logs to this repo. Pull requests containing them will be closed.
